PIR 업로더(이하 "본 서비스")는 운영자 본인이 촬영한 영상을 병합해 본인의 유튜브 채널에 업로드하기 위한 개인용 도구입니다. 일반 이용자에게 제공되지 않습니다.

1. 수집하는 정보

  • 구글 계정 연동 시 발급되는 OAuth 토큰 (유튜브 업로드 권한 youtube.upload 용도)
  • 업로드를 위해 임시로 저장되는 영상 파일 및 촬영 시각 등 메타데이터

2. 이용 목적

수집한 정보는 영상을 병합하고 운영자의 유튜브 채널에 업로드하는 목적으로만 사용합니다.

3. 보관 및 파기

영상 파일은 업로드가 완료되면 서버에서 즉시 삭제됩니다. OAuth 토큰은 서버에만 보관되며, 운영자가 구글 계정 설정에서 권한을 해제하면 더 이상 사용할 수 없습니다.

4. 제3자 제공

수집한 정보를 제3자에게 판매하거나 제공하지 않습니다. 영상 업로드를 위해 YouTube API 서비스로만 전송됩니다.

5. Google API 서비스 이용

본 서비스의 Google API 정보 이용은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
